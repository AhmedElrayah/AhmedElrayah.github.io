# Ahmed Elrayah — Senior Portfolio

A responsive, static portfolio prepared for GitHub Pages. No installation or build step is required.

## Publish

1. Create a public repository named `AhmedElrayah.github.io` in the AhmedElrayah account.
2. Upload the contents of this folder to the repository root (not the enclosing folder).
3. In Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
4. When GitHub finishes deployment, the expected address is https://AhmedElrayah.github.io/ . This address is not a claim that publication has already happened.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Pages

- index.html: introduction, full opening statement, and areas of interest.
- resume.html: confirmed academic background and space for a full résumé.
- projects.html: portfolio section, explicitly marked as awaiting artifacts.
- styles.css: shared responsive design and print styles.
- site.js: mobile navigation and statement printing.
